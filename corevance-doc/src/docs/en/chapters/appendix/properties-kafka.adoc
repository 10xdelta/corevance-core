= Kafka Properties

.Kafka related properties for Remote Spring Batch Jobs
|===
|Name |Env Variable |Default Value |Description

|corevance.remote-job-message-handler.kafka.enabled
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_ENABLED
|false
|Enables or disables Kafka for remote job execution. If Kafka is enabled then JMS shall be disabled.

|corevance.remote-job-message-handler.kafka.topic.auto-create
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_TOPIC_AUTO_CREATE
|true
|Enables topic auto creation. In case the auto creation of the topic is disabled please make sure that the replica and the partition count is properly configured.

|corevance.remote-job-message-handler.kafka.topic.name
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_TOPIC_NAME
|job-topic
|Name of the topic where partitioned tasks are sent to

|corevance.remote-job-message-handler.kafka.topic.replicas
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_TOPIC_REPLICAS
|1
|Number of the replicas

|corevance.remote-job-message-handler.kafka.topic.partitions
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_TOPIC_PARTITIONS
|10
|Number of partitions

|corevance.remote-job-message-handler.kafka.bootstrap-servers
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_BOOTSTRAP_SERVERS
|localhost:9092
|Comma separated list of bootstrap servers

|corevance.remote-job-message-handler.kafka.consumer.group-id
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_CONSUMER_GROUPID
|corevance-consumer-group-id
|Group ID of the Consumer

|corevance.remote-job-message-handler.kafka.consumer.extra-properties-key-value-separator
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_CONSUMER_EXTRA_PROPERTIES_SEPARATOR
|=
|Defines key and value separator for consumer,e.g.: key=value

|corevance.remote-job-message-handler.kafka.consumer.extra-properties-separator
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_CONSUMER_EXTRA_PROPERTIES_SEPARATOR
|\|
|Defines item separator for consumer, e.g.: key1=value1\|key2=value2

|corevance.remote-job-message-handler.kafka.consumer.extra-properties
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_CONSUMER_EXTRA_PROPERTIES
|
|#holds list of key value pairs using the above defined separators for consumer:  key1=value1\|key2=value2\|...\|keyn=valuen

|corevance.remote-job-message-handler.kafka.producer.extra-properties-key-value-separator
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_PRODUCER_EXTRA_PROPERTIES_KEY_VALUE_SEPARATOR
|=
|Defines key and value separator for producer,e.g.: key=value

|corevance.remote-job-message-handler.kafka.producer.extra-properties-separator
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_PRODUCER_EXTRA_PROPERTIES_SEPARATOR
|\|
|Defines item separator for producer, e.g.: key1=value1\|key2=value2

|corevance.remote-job-message-handler.kafka.producer.extra-properties
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_PRODUCER_EXTRA_PROPERTIES
|
|#holds list of key value pairs using the above defined separators for producer:  key1=value1\|key2=value2\|...\|keyn=valuen

|corevance.remote-job-message-handler.kafka.admin.extra-properties-key-value-separator
|COREVANCE_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_ADMIN_EXTRA_PROPERTIES_KEY_VALUE_SEPARATOR
|=
|Defines key and value separator for admin,e.g.: key=value
