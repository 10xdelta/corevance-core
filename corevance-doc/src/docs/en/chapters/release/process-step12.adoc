= Step 12: Upload Distribution Release

== Description

Move the release candidate from the dev area to the release area using a Subversion server-side copy.

[source,bash,subs="attributes+"]
----
# this is a remote operation
svn mv -m "Release Corevance {revnumber} 🚢" \
  https://dist.apache.org/repos/dist/dev/corevance/{revnumber} \
  https://dist.apache.org/repos/dist/release/corevance/
----

NOTE: https://www.apache.org/legal/release-policy.html#upload-ci[This must be done by a Corevance PMC member].

You will now get an automated email from the Apache Reporter Service (no-reply@reporter.apache.org), subject "Please add your release data for 'corevance'" to add the release data (version and date) to the database on https://reporter.apache.org/addrelease.html?corevance (requires PMC membership).

== Gradle Task

.Command
[source,bash,subs="attributes+,+macros"]
----
./gradlew corevanceReleaseStep12 -Pcorevance.release.version={revnumber}
----

CAUTION: This task is not yet automated!
